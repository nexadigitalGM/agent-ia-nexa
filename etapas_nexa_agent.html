Fluxo de Implementação

Passo a Passo para Criar o App Nexa Agent

Roteiro técnico e operacional simplificado para desenvolvimento e publicação gratuita

01
Geração da Chave de API Gratuita

Obtenção das credenciais oficiais para alimentar a inteligência do copiloto.

  • Acessar o ambiente de desenvolvimento do Google AI Studio com sua conta Google.
  • Abrir o menu lateral e selecionar a opção de Chaves de API (Get API Key).
  • Criar uma nova chave vinculada ao projeto padrão e copiá-la para um local seguro.
02
Estruturação dos Arquivos Locais

Preparação do ambiente do projeto no seu computador.

  • Criar uma pasta dedicada para o projeto (ex.: nexa-agent).
  • Criar o arquivo de dependências (requirements.txt) com as bibliotecas necessárias.
  • Criar o arquivo da aplicação (app.py) contendo as regras e comandos da Nexa Digital.
03
Testes e Execução Local

Validação da interface, dos comandos rápidos e da análise visual de prints.

  • Instalar as dependências via terminal.
  • Iniciar o servidor local e abrir a interface web no navegador.
  • Inserir a chave de API e validar os comandos (MENU, DIAGNÓSTICO EXPRESS, envio de fotos).
04
Publicação do Projeto no GitHub

Versionamento online para permitir o deploy contínuo e automático.

  • Criar um novo repositório no GitHub (público ou privado).
  • Fazer o upload dos arquivos app.py e requirements.txt para a branch principal.
05
Hospedagem em Nuvem 100% Gratuita

Disponibilização de um link web acessível para toda a equipe.

  • Conectar a conta do GitHub na plataforma Streamlit Cloud.
  • Selecionar o repositório criado e apontar para o arquivo principal da aplicação.
  • Cadastrar a chave de API nas configurações secretas (Secrets) da nuvem.
  • Realizar o deploy e compartilhar o link oficial com os membros da equipe.

📌 Padrão Operacional Ativo

O aplicativo opera sob custo zero, integrado ao modelo de alta velocidade, preparado para leitura de prints de perfis e alinhado aos preços e diretrizes oficiais da Nexa Digital.
